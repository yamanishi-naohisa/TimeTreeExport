# TimeTreeExport

TimeTreeのデータをエクスポートするためのPythonスクリプト

## 概要

このプロジェクトは、TimeTreeからカレンダーデータをエクスポートするためのツールです。

## セットアップ

```bash
# 仮想環境の作成（推奨）
python -m venv venv

# 仮想環境の有効化
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

# 依存パッケージのインストール
pip install -r requirements.txt
```
